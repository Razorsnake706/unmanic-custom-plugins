# File Size Metrics Plus

A richer local analytics panel for Unmanic completion history.

- Filter by date, status, library, source/output codec, worker, size change, and percent saved.
- Search, sort, paginate, inspect task details, and export filtered results to CSV.
- Records before/after size plus codec, profile, resolution, pixel format, audio, worker, and duration for new tasks.
- Imports the official File Size Metrics history database without modifying it.
- Stores its data separately, so it can coexist with the official plugin during migration.
