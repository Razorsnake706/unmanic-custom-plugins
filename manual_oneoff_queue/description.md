# Manual One-Off Queue

Adds a manual queue panel to Unmanic for one-off processing jobs.

Choose a source library, browse to a single movie or episode, select exactly which installed processing plugins should run, set their order, and queue that file without changing your normal TV/Movie plugin flow.

For task-specific plugin selection, use a dedicated scanner-disabled manual library with this controller as its only worker-process plugin. Selected plugins borrow settings from the chosen source library.
